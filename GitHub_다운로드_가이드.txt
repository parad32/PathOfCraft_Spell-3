========================================
  GitHub에서 다운로드 및 설치 가이드
========================================

이 문서는 GitHub에서 처음 다운로드하는 분들을 위한 
단계별 설치 가이드입니다.


📌 전체 과정 요약
-----------------
1. GitHub에서 파일 다운로드 (1분)
2. 압축 해제 (10초)
3. Python 설치 (5분)
4. 의존성 설치 (3분)
5. 프로그램 실행!


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


🌐 1단계: GitHub에서 다운로드
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1) 웹브라우저를 열고 아래 주소로 이동하세요
   https://github.com/parad32/PathOfCraft_Spell-3

2) 페이지 상단에 초록색 "<> Code" 버튼을 찾으세요

3) "<> Code" 버튼 클릭

4) 나타난 메뉴에서 "Download ZIP" 클릭

5) 파일이 다운로드됩니다
   (파일명: PathOfCraft_Spell-3-main.zip)

💡 TIP: 다운로드 폴더에 저장됩니다 (보통 C:\Users\사용자명\Downloads)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


📂 2단계: 압축 해제
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1) 다운로드한 "PathOfCraft_Spell-3-main.zip" 파일 찾기

2) 파일에 마우스 오른쪽 클릭

3) "압축 풀기" 또는 "Extract All..." 선택

4) 원하는 위치 선택 (예: 바탕화면, 내문서 등)
   추천: C:\PathOfCraft\매크로 같은 짧은 경로

5) "압축 풀기" 또는 "Extract" 버튼 클릭

6) 압축이 풀리면 "PathOfCraft_Spell-3-main" 폴더가 생성됩니다

💡 TIP: 폴더 이름을 "옵션감지매크로"로 바꿔도 좋습니다


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


🐍 3단계: Python 설치
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚠️ 이미 Python이 설치되어 있다면 이 단계를 건너뛰세요.
   (확인 방법: 명령 프롬프트에서 "python --version" 입력)

1) 웹브라우저에서 아래 주소로 이동
   https://www.python.org/downloads/

2) 큰 노란색 "Download Python" 버튼 클릭
   (최신 버전이 자동으로 다운로드됩니다)

3) 다운로드한 파일 실행
   (예: python-3.13.3-amd64.exe)

4) ⚠️⚠️⚠️ 중요! ⚠️⚠️⚠️
   설치 화면 맨 아래에
   ☑ "Add Python to PATH" 체크박스를 반드시 체크!
   
   이걸 안 하면 나중에 프로그램이 작동하지 않습니다!

5) "Install Now" 클릭

6) 설치 진행 (1~2분 소요)

7) "Setup was successful" 메시지가 나오면 "Close" 클릭

8) 설치 확인:
   - Windows 키 + R 누르기
   - "cmd" 입력 후 Enter
   - 검은 창(명령 프롬프트)이 뜨면
     "python --version" 입력 후 Enter
   - "Python 3.13.3" 같은 메시지가 나오면 성공!

💡 TIP: Python 버전은 3.9 이상이면 됩니다


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


📦 4단계: 의존성 설치
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

이제 프로그램 실행에 필요한 패키지를 설치합니다.
(처음 한 번만 하면 됩니다)

1) 압축 해제한 폴더로 이동
   (PathOfCraft_Spell-3-main 폴더)

2) "1_의존성설치.bat" 파일 찾기

3) "1_의존성설치.bat" 파일을 더블클릭

4) 검은 창이 뜨면서 자동으로 설치가 진행됩니다
   (2~3분 소요, 인터넷 연결 필요)

5) 설치 중 화면에 여러 메시지가 나타납니다
   - "Collecting easyocr..."
   - "Installing collected packages..."
   - 이런 메시지들은 정상입니다!

6) 마지막에 이 메시지가 나오면 성공!
   "========================================
    ✓ 설치 완료!
    ========================================
    
    이제 '2_매크로실행.bat' 파일을 실행하세요!"

7) 아무 키나 눌러서 창 닫기


⚠️ 문제 해결
-------------

문제1: "Python이 설치되어 있지 않습니다!" 오류
해결: 3단계로 돌아가서 Python을 설치하세요
     설치 시 "Add Python to PATH" 체크 필수!

문제2: 설치 중 오류가 계속 나타남
해결: 1) 인터넷 연결 확인
     2) 백신 프로그램 잠시 끄기
     3) 방화벽 설정 확인

문제3: "pip is not recognized..." 오류
해결: Python을 재설치하면서 "Add Python to PATH" 체크

🚀 5단계: 프로그램 실행
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

설치가 완료되었으니 이제 프로그램을 실행합니다!

1) 압축 해제한 폴더에서 "2_매크로실행.bat" 파일 찾기

2) "2_매크로실행.bat" 파일을 더블클릭

3) 검은 창(명령 프롬프트)이 뜨고 잠시 후
   프로그램 창이 나타납니다

4) 첫 실행 시 "Using CPU..." 메시지가 나타나고
   EasyOCR 모델을 다운로드합니다 (1~2분, 약 200MB)
   인터넷 연결이 필요하며, 이후에는 오프라인 사용 가능!

5) 프로그램 창이 뜨면 성공!

⚠️ 중요: 검은 창(cmd)을 닫으면 프로그램도 종료됩니다!
        검은 창은 최소화만 하고 사용하세요

🎯 6단계: 프로그램 사용
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

프로그램이 실행되었으니 이제 사용해봅시다!

1) 인식 영역 설정
   - F7 키를 누릅니다
   - 화면이 어두워지면 마우스로 드래그하여
     게임에서 텍스트가 나타나는 영역을 선택합니다
   - 빨간 테두리가 표시되면 설정 완료!

2) 매크로 시작
   - 게임에서 클릭할 위치에 마우스 커서를 이동
   - F8 키를 누릅니다
   - 자동으로 클릭이 시작됩니다

3) "모든 주문 스킬 레벨 +3" 감지
   - 옵션이 나타나면 자동으로 중단됩니다
   - 축하 팝업이 뜹니다!

4) 긴급 정지
   - F9 또는 F10 키를 누르면 즉시 중단됩니다


⌨️ 핫키 정리
-------------
F7  : 인식 영역 설정
F8  : 매크로 시작/정지
F9  : 긴급 정지
F10 : 긴급 정지
ESC : 팝업 닫기

💡 자주 묻는 질문 (FAQ)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q1: Python이 설치되어 있는지 확인하는 방법?
A1: Windows 키 + R → "cmd" 입력 → "python --version" 입력
    버전이 나오면 설치된 것입니다.

Q2: "Add Python to PATH"를 체크 안 했는데 어떻게 하나요?
A2: Python을 다시 설치하거나,
    제어판 → 프로그램 제거 → Python 제거 → 재설치

Q3: 필요한 저장 공간은?
A3: Python (100MB) + 패키지 (800MB) + OCR 모델 (200MB)
    = 약 1.1GB

Q4: 오프라인에서도 사용할 수 있나요?
A4: 첫 설치와 첫 실행은 인터넷 필요
    이후에는 오프라인 사용 가능

Q5: 매번 의존성 설치를 해야 하나요?
A5: 아니요! "1_의존성설치.bat"는 처음 한 번만 실행하면 됩니다.
    이후에는 "2_매크로실행.bat"만 실행하세요.

Q6: 프로그램을 업데이트하려면?
A6: GitHub에서 다시 다운로드 → 압축 해제 → 
    의존성 설치는 건너뛰고 바로 실행

Q7: 백신 프로그램이 차단해요
A7: 배치 파일(.bat)을 종종 의심하지만 안전합니다.
    신뢰할 수 있는 파일로 추가하세요.

Q8: 다른 컴퓨터에 설치하려면?
A8: 이 가이드를 처음부터 다시 따라하세요.
    각 컴퓨터마다 Python과 의존성 설치가 필요합니다.
