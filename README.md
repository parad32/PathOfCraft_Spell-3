# 옵션 감지 매크로 (Option Detector Macro)

**Path of Exile / Path of Craft** 게임에서 특정 옵션을 자동으로 감지하는 매크로 프로그램입니다.

---

## 📋 주요 기능

- **실시간 OCR 텍스트 인식**: 지정한 화면 영역의 텍스트를 실시간으로 읽습니다
- **자동 클릭**: Shift + 클릭을 자동 실행 (기본 100ms 간격, 10ms 단위로 조절 가능)
- **목표 옵션 감지**: "모든 주문 스킬 레벨 +3" 옵션을 정확히 감지
- **제외 옵션 카운팅**: 투사체/소환수/근접 옵션을 넘긴 횟수 표시
- **연속 제작 모드**: 여러 아이템을 자동으로 순차 제작 (최대 12개)
- **즉시 중단**: 목표 옵션 발견 시 클릭하기 전에 즉시 중단
- **백그라운드 핫키 지원**: 게임 화면에서도 핫키 작동
- **실시간 마우스 좌표**: 현재 마우스 위치를 실시간으로 표시

---

## 🎯 감지 대상 옵션

### ✅ 성공 조건
다음 **모든 조건**을 만족하는 옵션만 감지합니다:

1. **"모든"** 키워드 포함
2. **"주문"** 키워드 포함
3. **"스킬"** 키워드 포함
4. **"레벨"** 키워드 포함
5. **"+3"** 숫자 포함 (반드시 3)

### ❌ 제외 조건
다음 키워드가 포함되면 **제외**됩니다:
- 소환수
- 투사체
- 근접

### 예시
- ✅ **성공**: "모든 주문 스킬 레벨 +3"
- ❌ **실패**: "모든 주문 스킬 레벨 +1" (숫자가 1)
- ❌ **실패**: "모든 주문 스킬 레벨 +2" (숫자가 2)
- ❌ **실패**: "모든 근접 스킬 레벨 +3" (근접 키워드 포함)
- ❌ **실패**: "모든 투사체 스킬 레벨 +3" (투사체 키워드 포함)

### Installation (One Time Only)

**Step 1: Install Python**
1. Visit https://www.python.org/downloads/
2. Download and install latest version
3. ⚠️ **CRITICAL**: Check "Add Python to PATH" during installation!

**Step 2: Install Dependencies**
1. Double-click `1_install.bat`
2. Packages will install automatically (~2-3 minutes)

### Run Program (Every Time)

Double-click `2_run.bat`

### 2단계: 인식 영역 설정
1. **F7 키** 또는 "인식 영역 설정" 버튼 클릭
2. 화면이 어두워지면 마우스로 **드래그**하여 인식할 영역 지정
3. 빨간 테두리가 표시되면 설정 완료

💡 **팁**: 게임에서 옵션 텍스트가 표시되는 영역만 지정하세요

### 3단계: 매크로 시작
1. 게임 화면에서 클릭할 위치에 **마우스 커서 이동**
2. **F8 키** 누르기 → 매크로 시작
3. 자동으로 클릭이 시작되고 OCR이 텍스트를 계속 확인합니다

### 4단계: 목표 감지
- 목표 옵션이 감지되면:
  - ✅ **클릭하지 않고 즉시 중단**
  - 🎉 축하 팝업이 표시됨
  - 총 클릭 횟수 확인 가능
  - 넘긴 제외 옵션 통계 확인 (투사체/소환수/근접)

### 5단계: 정지
- **F8 키**: 매크로 시작
- **F9 / F10 키**: 매크로 정지 (언제든지 즉시 중단)

💡 **Shift 키는 매크로 시작 시 자동으로 활성화되고, 종료 시 자동으로 해제됩니다!**

## ⚙️ 동작 원리

### 매크로 실행 순서
```
1. OCR로 화면 텍스트 확인
2. 목표 옵션 감지?
   → YES: 클릭하지 않고 즉시 중단 ✅
   → NO: 클릭 실행 → 설정된 간격만큼 대기 → 1번으로 돌아가기
```

### Shift 키 관리
매크로가 시작되면 자동으로 Shift 키가 눌리고, 종료되면 자동으로 해제됩니다.
사용자가 별도로 Shift를 관리할 필요가 없습니다!

### 왜 클릭 전에 OCR을 체크하나요?
이전 버전은 클릭과 OCR이 병렬로 실행되어서 목표 옵션이 감지되어도 **이미 다음 클릭이 실행되어 옵션이 넘어가는 문제**가 있었습니다.

현재 버전은 **클릭 전에 OCR을 먼저 확인**하므로 목표 옵션을 놓치지 않습니다!

## 📊 OCR 오인식 대응

한글 OCR은 비슷한 자음/모음을 자주 혼동합니다. 이 프로그램은 다음 변형들을 모두 인식합니다:

### 모든
- 모듬, 모둔, 모돈, 보든, 묘든, 모드 등 (28개 변형)

### 주문
- 주뭄, 주믄, 쥬문, 추문, 쭈문, 죠문 등 (29개 변형)

### 스킬
- 스길, 스킨, 쓰킬, 즈킬, 슥킬, 스컬 등 (28개 변형)

### 레벨
- 레벌, 레밸, 래벨, 네벨, 려벨, 뢰벨 등 (35개 변형)

## 🎮 사용 팁

### 최적의 설정
1. **인식 영역은 작게**: 옵션 텍스트만 포함되도록
2. **배경은 깨끗하게**: 다른 텍스트가 겹치지 않도록
3. **해상도 확인**: 텍스트가 선명하게 보이는지 확인

### 문제 해결
- **Python이 없다고 나올 때**: Python 설치 시 "Add Python to PATH"를 체크하셨는지 확인하세요
- **의존성 설치 실패**: 인터넷 연결 확인 및 방화벽/백신 설정 확인
- **감지가 안 될 때**: 인식 영역을 다시 설정해보세요
- **오감지가 많을 때**: 인식 영역을 더 작게 조정하세요
- **프로그램이 멈을 때**: F9/F10으로 긴급 정지 후 재시작
