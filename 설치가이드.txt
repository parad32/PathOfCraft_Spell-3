========================================
  옵션 감지 매크로 - 설치 가이드
========================================

📦 필요한 것
-----------
1. Python 3.9 이상
2. 인터넷 연결 (첫 설치 시)
3. 약 1GB의 저장 공간


🚀 설치 방법 (2단계)
--------------------

[1단계] Python 설치
-------------------
1. https://www.python.org/downloads/ 방문
2. "Download Python" 클릭 (최신 버전)
3. 다운로드한 파일 실행
4. ⚠️ 중요: "Add Python to PATH" 체크 필수!
5. "Install Now" 클릭
6. 설치 완료 (약 1분 소요)


[2단계] 의존성 설치
-------------------
1. "1_의존성설치.bat" 더블클릭
2. 자동으로 필요한 패키지 설치 (약 2~3분)
3. "설치 완료!" 메시지 확인


✅ 실행 방법
-----------
"2_매크로실행.bat" 더블클릭

→ 프로그램 창이 뜨면 사용 시작!


⌨️ 핫키
-------
F7  : 인식 영역 설정
F8  : 매크로 시작/정지
F9  : 긴급 정지
F10 : 긴급 정지


🎯 사용 순서
-----------
1. "2_매크로실행.bat" 실행
2. F7 키 → 마우스로 텍스트 영역 드래그
3. 게임에서 클릭할 위치에 마우스 이동
4. F8 키 → 매크로 시작
5. "모든 주문 스킬 레벨 +3" 감지 시 자동 중단!


💡 문제 해결
-----------
Q: Python이 설치되어 있는데 안 된다고 나와요
A: Python 설치 시 "Add Python to PATH"를 체크하지 않으셨습니다.
   Python을 재설치하거나, 환경 변수에 수동으로 추가하세요.

Q: 의존성 설치가 안 돼요
A: 인터넷 연결을 확인하세요.
   방화벽이나 백신 프로그램이 차단하고 있을 수 있습니다.

Q: 프로그램이 느려요
A: 첫 실행 시 EasyOCR 모델을 다운로드합니다 (약 200MB).
   인터넷에서 자동으로 다운로드하며, 한 번만 하면 됩니다.

Q: 감지가 안 돼요
A: F7으로 인식 영역을 텍스트만 포함되도록 작게 설정하세요.

Q: 필요한 공간이 얼마나 되나요?
A: Python (100MB) + 패키지 (800MB) + OCR 모델 (200MB) = 약 1.1GB


📋 파일 구조
-----------
1_의존성설치.bat    ← 처음 한 번만 실행
2_매크로실행.bat    ← 매크로 실행 (매번)
설치가이드.txt      ← 이 파일
README.md           ← 상세 설명서
main.py             ← 프로그램 소스
requirements.txt    ← 의존성 목록


⚠️ 주의사항
-----------

- 매크로 사용 중에는 배치 파일 창을 최소화만 하세요
- 백신 프로그램이 경고할 수 있으나 안전합니다
