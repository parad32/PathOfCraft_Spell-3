========================================
  옵션 감지 매크로 v1.0
========================================

Path of Exile / Path of Craft 게임에서
"모든 주문 스킬 레벨 +3" 옵션을 자동으로 감지하는 프로그램입니다.


🚀 빠른 시작 (3단계)
--------------------

1️⃣ Python 설치
   https://www.python.org/downloads/
   → "Add Python to PATH" 체크 필수!

2️⃣ "1_의존성설치.bat" 실행
   → 자동으로 패키지 설치 (2~3분)

3️⃣ "2_매크로실행.bat" 실행
   → 프로그램 시작!


⌨️ 핫키
-------
F7  - 인식 영역 설정
F8  - 매크로 시작/정지
F9  - 긴급 정지
F10 - 긴급 정지


📖 자세한 사용법
---------------
"설치가이드.txt" 또는 "README.md" 파일을 참고하세요.


❓ 문제 발생 시
--------------
1. "설치가이드.txt" 파일의 "문제 해결" 섹션 확인
2. Python이 제대로 설치되었는지 확인
   (명령 프롬프트에서 "python --version" 입력)


⚠️ 주의사항
-----------
- 매크로 실행 시 나타나는 검은 창(cmd)을 닫으면 안 됩니다
- 최소화만 하고 사용하세요
- 게임 이용 약관을 확인하고 사용하세요
